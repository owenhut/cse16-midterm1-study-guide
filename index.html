Four lenses: What exists? (Sets) → What follows? (Logic) → Does it always hold? (Quantifiers) → How many? (Counting) → Can you prove it? (Truth Tables). Master these and you own the exam.

Part B — Sets

Slide 1: Sets — Notation & Basics

Definition
  • A set = unordered collection of distinct objects: A = {1,2,3}
  • x ∈ A = x is an element of A  ·  x ∉ A = x is NOT an element
  • A ⊆ B = every element of A is in B (subset)
  • A = B iff A ⊆ B AND B ⊆ A (mutual containment)
  • ∅ = empty set. ∅ ⊆ A for ANY set A — even ∅ ⊆ ∅
Trap — ∈ vs ⊆

Given A = {2, {2,{2}}}: Is {2} ∈ A? NO — it's not listed as an element (A has elements 2 and {2,{2}} — not {2}). Is 2 ∈ A? YES. ∈ asks "is this an element at the outermost level?"

Practice

True or False: ∅ ∈ {∅, {∅}}

TRUE. ∅ is listed as an element of the set. {∅, {∅}} has two elements: ∅ and {∅}.

Part B — Sets

Slide 2: Set Cardinality

Definition
  • |A| = number of elements in A (count at outermost level only)
  • |∅| = 0
  • |{∅}| = 1 — one element: the empty set itself
  • |{∅, {∅}}| = 2
  • |{ {1,2}, 3, ∅ }| = 3 — count items at top level
Exam Trap — Q18: |{∅}| = 0?

{∅} looks empty but has cardinality 1. The exam states |{∅}| = 0 — this is FALSE. The bag contains one item (an empty bag). Don't peek inside inner sets.

Analogy

Cardinality = how many things are in the outer bag. A bag with an empty bag inside has 1 item. Count items; don't open them.

Practice

What is |{ {1,2}, {3}, ∅, 5 }|?

4. Four items at the outer level: {1,2}, {3}, ∅, and 5.
Part B — Sets

Slide 3: Cartesian Products

Definition
  • A×B = {(a,b) | a∈A, b∈B} — all ordered pairs
  • |A×B| = |A|·|B|
  • Distributes over ∩: A×(C∩D) = (A×C)∩(A×D) ← TRUE
  • Distributes over ∪: A×(C∪D) = (A×C)∪(A×D) ← TRUE
Exam Trap — Q17: Union version is FALSE

The exam states: "If B = C∩D, then A×B = (A×C)∪(A×D)" — this is FALSE. If B = C∩D, then A×B = A×(C∩D) = (A×C)∩(A×D). The exam uses ∪ — that's the trap. The correct distribution uses the SAME operation (∩→∩, not ∩→∪).

Practice

If |A|=3 and |B|=4, what is |A×B|? And |B×A|?

Both are 12. Cardinality of Cartesian product = product of cardinalities regardless of order.

A. Since A⊆B, every element of A is in B. The intersection is exactly A. Q15 = TRUE.
Part B — Sets

Slide 5: Power Sets

Definition
  • P(A) = set of ALL subsets of A (including ∅ and A itself)
  • |P(A)| = 2^|A|
  • P(∅) = {∅}, so |P(∅)| = 1
  • P(A∩B) = P(A)∩P(B) — TRUE (Q7)
  • |P(A∪B)| = 2^(|A|+|B|−|A∩B|) — TRUE (Q13, inclusion-exclusion in exponent)
Exam Trap — Q6: |P({a,b,c})| = 2?

|P({a,b,c})| = 2³ = 8, not 2. Statement is FALSE. n=3 elements → 2³=8 subsets.

Analogy — Light Switches

n elements = n switches. Each subset = one on/off pattern. 3 switches → 2³ = 8 power set elements.

Practice

How many elements does P({∅, {1}, 2}) have?

8. The set has 3 elements (∅, {1}, 2) → |P| = 2³ = 8.

Part A — Quantifiers Theory

Slide 10: Quantifiers — Theory & Negation

The Two Quantifiers
SymbolRead asTrue when…
∀x P(x)"For ALL x, P(x)"P holds for EVERY x in domain
∃x P(x)"There EXISTS x, P(x)"P holds for at LEAST ONE x
Order Matters — ∀∃ ≠ ∃∀

∀x∃y P(x,y): for each x, find a y (y can depend on x).
∃y∀x P(x,y): one single y works for ALL x (much stronger).
These are NOT equivalent in general.

Negation Algorithm — 3 Steps
  • Step 1: Push ¬ inward past quantifiers, flipping each: ¬∀ → ∃, ¬∃ → ∀
  • Step 2: Flip ALL quantifiers encountered on the way in
  • Step 3: Negate the final predicate

Laws: ¬∀x P(x) ≡ ∃x ¬P(x)  ·  ¬∃x P(x) ≡ ∀x ¬P(x)

Analogy — Nested Loops

∀x∃y = outer for-loop (all x), inner search (find a y). The y can depend on x.
∃y∀x = find ONE y first, then it must work for every x. Much harder claim.

Practice

Negate: ∃x∀y (x+y=0)

∀x∃y (x+y≠0) — flip ∃→∀, flip ∀→∃, negate predicate (= becomes ≠).
Part A — Q1 (2 pts)

Slide 11: Q1 — Quantifiers in a Set Formula

The Statement

∀A⊆U, ∀B⊆U, |P(A∪B)| = 2^(|A|+|B|−|A∩B|)

Q1 asks you to analyze this expression — identify the quantifier structure and/or evaluate it.

MCQ Setup — Answer: D

The statement uses two universal quantifiers: ∀A and ∀B (both ranging over subsets of U). The formula itself is TRUE (it's the inclusion-exclusion formula for power sets: |P(A∪B)| = 2^|A∪B| = 2^(|A|+|B|−|A∩B|)).

Walkthrough
  • Count quantifier symbols: "∀A⊆U" = 1st ∀, "∀B⊆U" = 2nd ∀ → two universal quantifiers
  • The formula: |P(A∪B)| = 2^|A∪B| and |A∪B| = |A|+|B|−|A∩B| by inclusion-exclusion
  • So |P(A∪B)| = 2^(|A|+|B|−|A∩B|) — TRUE for all A,B⊆U
Common Mistake

Thinking the subscript "⊆U" is a separate quantifier symbol. It's a domain restriction, not an additional ∀ or ∃. There are exactly two ∀ symbols: one for A, one for B.

Self-Check

How many quantifier symbols appear in ∀x∈ℝ, ∃y∈ℝ, ∃z∈ℤ, y = zx²?

3 quantifiers: one ∀ (for x) and two ∃ (for y and z). The domain annotations ∈ℝ, ∈ℤ are restrictions, not extra quantifiers.
Part A — Q2 (2 pts)

Slide 12: Q2 — Negate a Nested Quantified Statement

The Statement to Negate

∀n ∃k ∃(a₁…aₙ) ∀i, aᵢ = aᵢ₊₁

In English: "For every n, there exists k and a sequence of length n, such that for all i, consecutive terms are equal."

MCQ Setup — Answer: C

The correct negation (Answer C):
∃n ∀k ∀(a₁…aₙ) ∃i, aᵢ ≠ aᵢ₊₁

Step-by-Step Negation
  • Start: ∀n ∃k ∃(a₁…aₙ) ∀i, aᵢ=aᵢ₊₁
  • Push ¬ in — flip EVERY quantifier:
  • ¬∀n → ∃n
  • ¬∃k → ∀k
  • ¬∃(a₁…aₙ) → ∀(a₁…aₙ)
  • ¬∀i → ∃i
  • Negate predicate: aᵢ=aᵢ₊₁ → aᵢ≠aᵢ₊₁
  • Result: ∃n ∀k ∀(a₁…aₙ) ∃i, aᵢ≠aᵢ₊₁
Trap

You must flip ALL quantifiers, not just the first one. Students often flip only ∀n→∃n and forget the inner ∃k, ∃(aᵢ), ∀i. Every single quantifier flips; only the predicate gets negated.

Practice

Negate: ∀x∈ℝ ∃y∈ℝ, x·y = 1

∃x∈ℝ ∀y∈ℝ, x·y ≠ 1 — flip ∀→∃, flip ∃→∀, negate = to ≠.
Part A — Q3 (2 pts)

Slide 13: Q3 — Translate English to Quantified Statement

The English Statement

"For all y∈ℝ, there exists x∈ℝ, there exists z∈ℤ, such that y = z·x²"

MCQ Setup — Answer: D

The correct formal translation (Answer D):
∀y∈ℝ, ∃x∈ℝ, ∃z∈ℤ, y = z·x²

Translation Strategy
  • "For all y∈ℝ" → ∀y∈ℝ
  • "there exists x∈ℝ" → ∃x∈ℝ
  • "there exists z∈ℤ" → ∃z∈ℤ
  • Predicate: y = z·x²
  • Order of quantifiers preserved = order in English sentence
English → Symbol Triggers
English PhraseSymbol
for all, for every, for any, for each∀
there exists, there is, some, at least one∃
Trap — Domain Matters

x∈ℝ (reals) vs z∈ℤ (integers) — the domain of each variable is part of the translation. Writing ∃z∈ℝ when the problem says z∈ℤ is wrong.

Practice

Is ∀n∈ℕ, ∃k∈ℕ, k > n true?

TRUE. For any n, pick k = n+1. The existential witness (k) depends on n, which is fine here since the ∀ comes first.

Conclusion: YES — Tautology

All 8 rows produce TRUE in the final column. Key insight: whenever LHS = F, the implication is vacuously TRUE regardless of RHS. Only row 8 has RHS=F, but LHS=F there too, so F⇒F = T.

Why Row 8 (F,F,F) Deserves Attention

P=F, Q=F, R=F: Q⇔R = F⇔F = T; LHS = F∧T = F; ¬P=T, Q∨R=F, RHS = T⇒F = F; but LHS⇒RHS = F⇒F = T. Don't confuse RHS=F with the final result being F.

Part C — Counting

Slide 16: Counting — Multiplication & Addition Principles

The Two Principles
  • Multiplication: Sequential independent choices → multiply: m ways then n ways = m×n total
  • Addition: Mutually exclusive alternatives → add: m ways OR n ways = m+n total
Decision Tree

Draw branches: each branch = one choice. Count leaves = total outcomes. Same-level branches = multiply. Separate cases = add.

Analogy

3 shirts × 4 pants = 12 outfits (AND → multiply). 3 red shirts + 4 blue shirts = 7 shirts to choose from (OR → add).

Practice

How many 3-letter codes use letters A–Z with no repetition?

26×25×24 = 15,600. First letter: 26 choices. Second: 25. Third: 24. Sequential independent → multiply.

Part C — Counting

Slide 19: Stars and Bars — Distributing Identical Items

When to Use

Distributing n identical items into k distinct groups:

  • 0 allowed per group: C(n+k−1, k−1)
  • At least 1 per group: C(n−1, k−1) (give 1 to each first, then distribute freely)
Analogy

n stars = items. k−1 bars = dividers between k groups. Arrange all of them: C(n+k−1, k−1) total arrangements.

Example

Distribute 10 identical candies to 3 kids (0 ok each):
n=10, k=3 → C(10+2, 2) = C(12,2) = 66

Practice

Distribute 8 identical pizzas to 3 groups, each must get ≥ 1:

C(7,2) = 21. At least 1 each → C(n−1, k−1) = C(8−1, 3−1) = C(7,2) = 21.

Part C — Counting

Slide 20: Pigeonhole Principle

The Principle

If n+1 objects go into n pigeonholes, at least one hole has ≥ 2.

Generalized: N objects into k holes → some hole has ≥ ⌈N/k⌉ objects.

Formula for Guarantee Questions

Max without guarantee = (max per group) × (number of groups)
Minimum to guarantee = max without + 1

Practice

Min students needed to guarantee 3 share a birthday month?

25. 12 months, max without 3 sharing = 2×12=24. 24+1=25.

Part C — Q20 (2 pts)

Slide 21: Q20 — Non-Adjacent Seating

The Problem

11 students and 5 judges sit in a row. No two judges may be adjacent. How many arrangements are there?

Strategy: Place Students First, Use Gaps
  • Step 1: Arrange 11 students in a row: 11! ways
  • Step 2: 11 students create 12 gaps (before, between, after): _ S _ S _ … _ S _
  • Step 3: Choose 5 of 12 gaps for judges (unordered): C(12,5)
  • Step 4: Arrange 5 judges in chosen gaps: 5!
Answer: 11! × C(12,5) × 5!

This guarantees no two judges are in the same gap (so never adjacent).

Trap — Gaps = n+1

n people in a row create n+1 gaps. 11 students → 12 gaps (don't forget the gap before the first student and after the last).

Part C — Q21 (2 pts)

Slide 22: Q21 — Pigeonhole at Tables

The Problem

There are 16 tables. What is the minimum number of people needed to guarantee at least 2 people share a table?

Solution
  • Pigeonholes = 16 tables
  • Max with NO table having 2 people = 1 per table = 16 people
  • One more person forces a shared table: 16 + 1 = 17
Answer: 17

17 people, 16 tables → by pigeonhole, at least one table has ≥ 2 people.

Part C — Q22 (2 pts)

Slide 23: Q22 — Stars & Bars (0 ok)

The Problem

16 votes are distributed among 4 teams. Each team can receive 0 or more votes. How many ways can the votes be distributed?

Solution — Stars & Bars (0 allowed)
  • n = 16 votes (identical items), k = 4 teams (distinct groups)
  • Formula: C(n+k−1, k−1) = C(16+3, 3) = C(19,3)
  • C(19,3) = 19!/(3!·16!) = (19·18·17)/(3·2·1) = 969
Answer: C(19,3) = 969

Slide 24: Q23 — No Two Consecutive in {1..32}

The Problem

What is the minimum number of integers you must choose from {1, 2, …, 32} to guarantee that two of them are consecutive?

  • Max set with no two consecutive: take ALL odd numbers {1,3,5,…,31} = 16 numbers

Part C — Q24 (2 pts)

Slide 25: Q24 — Guarantee ≥1 Vote from Each of 4 Teams

The Problem

11 students each vote for one of 4 teams. What is the minimum number of students who must vote to guarantee that every team receives at least 3 votes?

Solution — Worst Case + 1
  • Worst case: maximize students without ALL 4 teams reaching 3 votes
  • 3 teams could get 2 votes each = 6 votes, remaining all go to 4th team
  • But actual worst case: 3 teams each get exactly 2 votes, no team reaches 3 yet
  • Max before guarantee: give 2 to each of 4 teams = 8 students
  • 8 + 1 = 9 means at least one team gets ≥3
Answer: 9

9 students guarantees at least one team has ≥3 votes. (Verify from your exam PDF for exact problem wording.)

Part C — Q25 (2 pts)

Slide 26: Q25 — Can We Guarantee ALL 4 Teams Get ≥1 Vote?

The Problem

16 votes are distributed among 4 teams. What is the minimum number of votes needed to guarantee that every team receives at least 1 vote?

Answer: CANNOT Be Guaranteed

No matter how many total votes there are, all of them could theoretically go to just one team. There is no minimum number that guarantees all 4 teams get at least 1 — unless you have control over how votes are cast.

Why

Even with 16 votes, the distribution (16,0,0,0) is valid — all 16 go to Team 1. Since votes are free choices, no count of total votes prevents this. The guarantee is impossible.

Key Insight

Pigeonhole guarantees AT LEAST one hole has ≥ many items, not that EVERY hole has ≥1. For every hole to have ≥1, you'd need to control the distribution, not just the count.

Part C — Q26 (2 pts)

Slide 27: Q26 — Stars & Bars with ≥1 Constraint

The Problem

16 votes are distributed among 4 teams such that each team gets at least 1 vote. How many ways can this happen?

Solution — Stars & Bars (≥1 each)
  • Give 1 vote to each of the 4 teams first (mandatory): 4 votes used, 12 remain
  • Wait — actually use the direct formula: C(n−1, k−1) where n=votes, k=teams
  • C(16−1, 4−1) = C(15, 3)
  • C(15,3) = 15!/(3!·12!) = (15·14·13)/(3·2·1) = 455
Answer: C(15,3) = 455
Trap — 0-ok vs ≥1

0-ok: C(n+k−1, k−1) = C(19,3) = 969.   ≥1 each: C(n−1, k−1) = C(15,3) = 455. Don't confuse these — the difference is whether you subtract from n or add to it.

Part C — Q27 (2 pts)

Slide 28: Q27 — Choose 5 Voting Students from 11

The Problem

From 11 students, choose 5 to be the voting representatives. How many ways can this be done?

Solution
  • Unordered selection (the group {A,B,C,D,E} = {E,D,C,B,A})
  • No repetition (can't pick the same student twice)
  • Formula: C(11,5)
  • C(11,5) = 11!/(5!·6!) = (11·10·9·8·7)/(5·4·3·2·1) = 462
Answer: C(11,5) = 462
Part C — Q28 (2 pts)

Slide 29: Q28 — Ordered Voting with Repetition

The Problem

16 votes are cast one-by-one (in order), each for one of 4 teams. How many different sequences of votes are possible?

Solution
  • Each of the 16 votes independently chooses 1 of 4 teams
  • Order matters (vote 1 for Team A, vote 2 for Team B ≠ vote 1 for Team B, vote 2 for Team A)
  • Repetition allowed (multiple votes can go to same team)
  • Formula: n^r = 4^16 (ordered with repetition)
Answer: 4¹⁶

4^16 = 4,294,967,296

Trap — Don't Use C(n,r)

C(n,r) is for unordered, no-repeat. Here order matters AND repetition is allowed → nʳ formula.

Part C — Q29 (2 pts)

Slide 30: Q29 — Complement Method

The Problem

From 11 students (8 on the winning team, 3 on other teams), choose 2 to present. How many 2-person groups include at least 1 student from the winning team?

Solution — Complement Method
  • Total 2-person groups from 11: C(11,2) = 55
  • Groups with NO winning team member (all from 3 non-winners): C(3,2) = 3
  • At least 1 winner = Total − None: 55 − 3 = 52
Answer: 52
Complement Method — General Rule

When "at least 1" is hard to count directly:
|at least 1| = |total| − |exactly 0|
Always check if "exactly 0" is easier to count than "at least 1".

Note

Verify the exact problem setup (team sizes) against your exam PDF — the method (complement) and answer (52) are correct.
